# Francia slágerkutatás (2026-10-24)
Forrásonként egy TSV: év<TAB>előadó<TAB>cím<TAB>jel (helyezés / eladás / hetek). Forrás: en.wikipedia (WebFetch), később más források.
- legtobb_eladott.tsv: List of best-selling singles in France (eladás, db)
- top100_1990s.tsv, top100_2000s.tsv: French Top 100 singles of the decade (helyezés)
- no1_<év>.tsv: a francia lista első helyezettjei (hetek száma)
Szabály: csak francia vagy francia nyelvű (belga, svájci, québeci, frankofón afrikai/karibi) előadó dala kerül a listára; a külföldi slágerek csak jelként.
